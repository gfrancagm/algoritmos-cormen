> [!Question] Considere o problema de somar dois inteiros binários de $n$ bits, armazenados em dois arranjos de $n$ elementos $A$ e $B$. A soma dos dois inteiros deve ser armazenada em forma binária em um arranjo de $(n + 1)$ elementos $C$.
>  Enuncie o problema formalmente e escreva o pseudocódigo para somar os dois inteiros.

> [!answer]- Minha resposta
> Entrada: Dois arranjos $A$ e $B$ de tamanho $n$ com elementos $a_i, b_i \in \{0,1\}$
> Saída: Um arranjo $C$ de tamanho $n+1$ tal que cada elemento $c_i \in \{0, 1\}$ e $C$ seja a soma binária de $A$ e $B$.
> 
> ```
> SomaBinária(A, B):
> 	n = A.comprimento
> 	C é um arranjo de tamanho n+1 preenchido com 0
> 	for i = n downto 1
> 		if A[i] + B[i] = 1
> 			C[i+1] = C[i+1] + 1
> 		else if A[i] + B[i] = 2
> 			C[i] = C[i] + 1
> 		if C[i+1] = 2
> 			C[i+1] = 0
> 			C[i] = C[i] + 1			
> 	return C			
> ```


> [!todo]- Resposta do Gemini
> **Entrada:** Dois arranjos $A = \langle a_1, a_2, \dots, a_n \rangle$ e $B = \langle b_1, b_2, \dots, b_n \rangle$ de comprimento $n$, onde cada $a_i, b_i \in \{0, 1\}$, representando os inteiros binários: $$v_A = \sum_{i=1}^{n} a_i \cdot 2^{n-i} \quad \text{e} \quad v_B = \sum_{i=1}^{n} b_i \cdot 2^{n-i}$$
> **Saída:** Um arranjo $C = \langle c_1, c_2, \dots, c_{n+1} \rangle$ de comprimento $n+1$, onde cada $c_i \in \{0, 1\}$, tal que o valor do inteiro representado por $C$: $$v_C = \sum_{i=1}^{n+1} c_i \cdot 2^{n+1-i}$$ satisfaça a condição: $v_C = v_A + v_B$.
> ```
> SomaBinária(A, B): 
> 	n := A.comprimento 
> 	seja C um novo vetor de tamanho n + 1 
> 	vai_um := 0 
> 	
> 	para i := n downto 1 faça 
> 		soma := A[i] + B[i] + vai_um 
> 		C[i + 1] := soma mod 2 { O bit atual fica com o resto (0 ou 1) } 
> 		vai_um := soma div 2 { O vai-um recebe o quociente (0 ou 1) }
> 		 
> 	C[1] := vai_um { O bit mais significativo recebe o último vai-um } 
> 	retorne C
> ```
